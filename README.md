# 📋 FHIR 問卷調查系統

這是「HL7 FHIR 醫療資訊架構」的進階實作成果。
身為一個從 **醫療業轉職資訊業** 的工程師，我深知臨床上紙本表單（如：健康回報）在資料整合上的痛點。因此，我將課程，將傳統表單與國際醫療標準 **HL7 FHIR** 結合，達成醫療資料的數位化與標準化交換。

---

## 🚀 專案亮點

1. 能夠與醫療標準（FHIR 對接）
    * 1.1 成功與 HAPI FHIR Server 進行實時資料對接。
    * 1.2 開發期間使用 Postman 進行 API 測試，確保問卷結構（Questionnaire）與填答結果（QuestionnaireResponse）完全符合國際醫療規範。

2. 前後端分離架構
    * 2.1 前端 (Vue 3)：負責打造流暢、美觀的網頁介面。
    * 2.2 後端 (Express)：負責處理網路請求，並使用 Axios 串接遠端伺服器，同時透過 CORS 解決常見的跨域問題。

3. 使用的網頁開發技巧
    * 3.1 動態表單生成：利用 `v-for` 迴圈，讓網頁能根據後端下載的 JSON 資料，自動畫出對應的問卷題目。
    * 3.2 非同步資料載入：使用 `Async/Await` 確保網頁在成功抓到遠端問卷資料後，才呈現給使用者，提升操作體驗。

---

## 🛠️ 使用技術 (Tech Stack)

* **前端**：Vue 3、Axios、Vue Router
* **後端**：Node.js、Express、CORS
* **測試與伺服器**：Postman、HAPI FHIR Server
